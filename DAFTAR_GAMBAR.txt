CARA MEMASUKKAN GAMBAR (singkat)
--------------------------------
1. Beri nama file persis seperti daftar di bawah (huruf kecil, tanpa spasi).
   Contoh: kopi.png. Format yang dikenali: .png, .jpg, .jpeg, .webp
2. Masukkan semua file ke folder:  assets/images/
3. Hentikan aplikasi lalu jalankan ulang (F5). Hot reload tidak cukup.
4. Tidak perlu mengubah kode maupun pubspec.yaml.

DAFTAR NAMA FILE GAMBAR  (taruh semua di folder assets/images/)
==============================================================
Format .png (kecuali splash_bg.jpg). Jika file belum ada, aplikasi tetap
jalan dan memakai emoji pengganti. Disarankan gambar persegi, minimal
400x400 piksel.
